# SeatLock

A production-grade, high-concurrency seat reservation backend built with Node.js and TypeScript

## Objectives

- Prevent double booking under heavy concurrency
- Learn distributed systems concepts
- Build production-ready backend architecture
- Practice observability, security, and deployment

## Roadmap

- Phase 0 — Foundation
- Phase 0.5 — Authentication
- Phase 1 — Reservation Domain
- Phase 2 — Reservation Engine
